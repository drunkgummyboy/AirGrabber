# File map

- `main.py` — entry point: `--tray` (start hidden, `parse_options`), logging, single-instance lock (a second start shows the running window and exits 0), package check, Services, MainWindow, async Tk loop, shutdown, applying a background-downloaded update (`apply_staged`), tray icon stop, restart after an update (lock released first)
- `install.ps1` — one-command Windows installer (winget set up when missing: registered, else downloaded from winget's pinned GitHub release; Python via winget/python.org; app into %LOCALAPPDATA%\Programs\AirGrabber; shortcuts; the Prowlarr question and the failure report in small dark Windows Forms windows)
- `README.md` — GitHub front page: install / update / uninstall
- `app/bootstrap.py` — launch-time requirements check: pip-installs missing/outdated packages with a plain-tkinter progress window (stdlib only)
- `app/__init__.py` — APP_NAME, __version__
- `app/identity.py` — `APP_USER_MODEL_ID` (`drunkgummyboy.AirGrabber`, also install.ps1's `$AppId`) and `set_process_app_id` (main.py, before the first window or tray icon: AirGrabber's own taskbar group and notification name instead of Python's); ctypes, stdlib only, no-op off Windows
- `app/shortcut_app_id.cs` — C# helper compiled by Windows PowerShell 5.1's Add-Type: `[AirGrabber.ShortcutAppId]::Get` / `Set` a shortcut's (.lnk) AppUserModelID, keeping the rest of the shortcut; used by install.ps1 and app/services/powershell.py
- `app/single_instance.py` — InstanceLock: named mutex `Local\AirGrabber` + auto-reset event `Local\AirGrabber-show` (a second start sets it, the running copy polls it); ctypes, stdlib only, no-op off Windows
- `app/config.py` — AppPaths (data dir, db, posters, logs, torrents = APP-mode .torrent cache), logging setup
- `app/database.py` — schema + migrations (append-only; v2 = `tracked_shows.auto_since` + `auto_attempts`, every switch reset to off), Database (locked shared connection), LibraryRepository (incl. the auto-download switch and due / give-up queries), HistoryRepository, SettingsRepository; all SQL
- `app/models/domain.py` — Show, Episode, LibraryEntry, ShowDetails, LibraryStats, CalendarEntry, Movie, SearchKind, SearchRequest, TorrentRelease, DownloadRecord, GrabOutcome (SAVED/SENT/OPENED), QuickDownloadResult, auto-download events (AutoDownloaded / AutoGaveUp / AutoError) and AutoDownloadReport, TorrentApp, ProwlarrSetupResult, ImportMatch / AirdatesPreview (airdates.tv import preview)
- `app/models/settings.py` — Settings model (incl. the hidden `prowlarr_seeded_url` run-once marker, `setup_done` first-run flag and `last_run_version`; `auto_update`; `auto_download_new_shows`; tray: `keep_in_tray`, the `tray_notice_shown` marker, `start_with_windows`), DownloadMode (APP = open in the torrent program / REMOTE = send to the torrent program on a NAS or another computer / FOLDER = save to a folder, default; field `download_mode`), RemoteKind (SYNOLOGY / QBITTORRENT / TRANSMISSION, `.program` = short name) and the `remote_*` fields (`remote_configured`, pure `remote_ready`; a before-validator moves 2.0's `ds_*` keys into them, the next save prunes those), QualityProfile, Weekday
- `app/models/tvmaze.py` — TVMaze wire schemas → domain models
- `app/models/tmdb.py` — TMDB wire schemas → domain models (release-date/certification extraction)
- `app/models/types.py` — shared annotated field types, strip_html
- `app/services/__init__.py` — Services composition root (create/aclose)
- `app/services/library.py` — LibraryService: `show_details` (ShowDetails for the details window: tracked shows from the library, others from TVMaze kept 15 min in memory, never stored; pure `next_episode`, `downloaded_ids`), track/search/import (new shows get the auto-download switch per `auto_download_new_shows`), `set_auto_download`, `activity` (Tracked cards: latest grab of the past week + next episode, ShowActivity), incremental + periodic sync, calendar suggestions (cached TVMaze schedule), change listeners; calendar_range(); `find_matches` (names → TVMaze matches without tracking; shared best-hit rule with `import_shows`, a "(YYYY)" / "(US)" suffix prefers that year / country)
- `app/services/airdates.py` — airdates.tv import: `parse_export` ("Export your color selection" text → series ids), AirdatesClient (`show_name` via `/s?q=info:<id>`, one request at a time 0.3 s apart, one retry; an unknown id answers 500), AirdatesImportService (`services.airdates`: `find` → AirdatesPreview; import the ticked ids with `library.import_shows`), AirdatesError
- `app/services/tvmaze.py` — TVMazeClient (async, rate-limit aware retries), TVMazeError/TVMazeNotFound
- `app/services/images.py` — ImageCache: memory LRU of resized posters over a disk cache; deduped downloads
- `app/services/tmdb.py` — TMDBClient (v3 key or v4 token, retries, key never in logs/errors; `check_key` = one /authentication call for an unsaved key), TMDB* errors
- `app/services/discovery.py` — DiscoveryService: TV/movie dashboards (30 min cache), details (24 h), TMDB→TVMaze `resolve` (show details) and tracking, `check_tmdb_key`
- `app/services/settings.py` — SettingsService (in-memory current settings, validated updates serialized by a lock, listeners)
- `app/services/updates.py` — UpdateService: version check against GitHub, `install` (download + swap APP_ENTRIES with rollback), `stage` (download + unpack into `.update/new` with a ready marker) and `register_install`; `apply_staged` (main.py at exit: swap in a staged update newer than the files on disk, else delete it); never in a dev copy
- `app/services/startup.py` — start with Windows: the Startup-folder `AirGrabber.lnk` (pythonw, `main.py --tray`), pure `shortcut_spec`, `is_enabled` / `set_enabled` (written by PowerShell's WScript.Shell, removed by deleting it); injectable Startup folder; stdlib only
- `app/services/powershell.py` — `run_powershell` (Windows PowerShell 5.1 without a console window, extra environment variables, timeout; cancelling waits so a shortcut is never half-written), `powershell_exe`, `LOAD_HELPER` / `helper_env` (compile app/shortcut_app_id.cs once per run); injectable `PowerShellRunner`; stdlib only
- `app/services/app_identity.py` — `ensure_start_menu_app_id` (main.py, once per launch in the background): gives an older install's Start-menu AirGrabber.lnk the AppUserModelID when its Arguments start this install's main.py and it has none; never in a development copy or to other shortcuts; pure `first_argument` / `skip_reason` / `parse_read_output`; injectable runner and Start-menu folder
- `app/services/install_info.py` — `ensure_uninstall_entry`: the HKCU "Installed apps" entry, mirroring install.ps1's Register-Uninstaller (create when missing, else refresh DisplayVersion of this folder's entry only); injectable registry; stdlib only
- `app/services/downloads.py` — DownloadService.grab() by `download_mode`: FOLDER = .torrent → watch folder (direct link, then itorrents), else magnet → the remote program (RemoteDownloads, when configured); REMOTE = .torrent (direct link, then itorrents) or else a magnet (own / Prowlarr redirect / built from the hash) → the remote program (`add_torrent` / `add_magnet`, "Sent to <program>"); APP = .torrent → `AppPaths.torrents` cache (pruned to 50) or else a magnet (own / Prowlarr redirect / built from the hash), opened with os.startfile; history + listeners
- `app/services/torrent_app.py` — find_torrent_app() (read-only registry lookup of the magnet / .torrent handler, injectable reader, friendly names), install_qbittorrent() via winget, TorrentAppService (`services.torrent_app`)
- `app/services/search.py` — TorrentSearchService: request builders (`episode_request` also module-level), concurrent indexer search streaming SearchUpdates (per-indexer status, timeout (an indexer's own `search_timeout` wins), cancellation); pure build_queries / is_relevant / passes_settings / is_preferred / merge / quality helpers
- `app/services/picking.py` — pure pick_best / rank_releases for the one-click Download: likely-fake filter (exe/zip/rar/password/codec words, too-small sizes), dead torrents, single episode before a pack, ranking by quality profile, preferred group, seeders, known size
- `app/services/quick_download.py` — QuickDownloadService (`services.quick_download`): one download per target at a time (per-target lock; a target already in the history returns `already_downloaded` without searching) → search (30 s cap) → pick_best → DownloadService.grab; UI-independent
- `app/services/auto_download.py` — AutoDownloadService (`services.auto_download`): download new episodes of shows whose switch is on — `run_once` (lock; give up 3 days after airing, then due episodes 2 h after airing, least-tried then oldest first, max 5, through QuickDownloadService; a failed grab = one AutoError and the run stops), `run_periodic` (startup + every 30 min, from MainWindow._start), event `subscribe`
- `app/services/prowlarr_setup.py` — ProwlarrSetupService: finds a Prowlarr on this PC (%ProgramData%\Prowlarr\config.xml, `parse_config`), waits for /ping, verifies and saves URL + key when none is configured; then once per local Prowlarr adds the CURATED public sites (Prowlarr tests each), marker `prowlarr_seeded_url`
- `app/services/synology.py` — DownloadStationClient (DSM Web API discovery, POST login, DS2/DS task create from a magnet or an uploaded .torrent (multipart), logout); `DownloadStationError` = older name of RemoteError
- `app/services/remote.py` — what the remote torrent programs share: RemoteClient protocol (`kind`, `test`, `add_magnet`, `add_torrent`), RemoteError, HttpClients (short-lived clients honouring `remote_verify_tls`, cached SSL contexts), host / TLS / redirect failure texts without URLs or secrets
- `app/services/qbittorrent.py` — QBittorrentClient (Web API v2: form login "Ok."/"Fails.", Referer + Origin for its CSRF check, app/version, multipart torrents/add with `urls` / `torrents` + `savepath`, logout; no sign-in without a user name)
- `app/services/transmission.py` — TransmissionClient (RPC at `<url>/transmission/rpc`: 409 session-id handshake, Basic auth, `session-get` version, `torrent-add` with `filename` / `metainfo` + `download-dir`), `rpc_url`
- `app/services/remote_downloads.py` — RemoteDownloads (`services.remote`, also `services.station`): the client for `Settings.remote_kind` on every call (`client()`), `configured`, `kind`, `test()`; `make_clients`
- `app/indexers/` — torrent indexers (Strategy pattern): base (BaseIndexer contract incl. optional `search_timeout`, IndexerError, shared GET-JSON/retry helper with per-request timeout, USER_AGENT), apibay, eztv (by IMDb id, paged), bitsearch, yts (MOVIE only, base-URL fallback), prowlarr (X-Api-Key, 30 s search read timeout, 40 s cap, `test()`); `default_indexers()` builds all five
- `app/ui/main_window.py` — root window: header (mode switch, logo, search, settings), pages (reloaded on settings changes except off-page ones — connections, `download_mode`, `setup_done`, `auto_update`, `last_run_version`, `auto_download_new_shows`, the tray ones: `settings_affect_pages`), `tray` (TrayHost: WM_DELETE_WINDOW, `--tray` start hidden), status bar (update badge / "Restart to update", "Updated to v…" notice `update_notice`, Prowlarr setup message), background update staging, update + restart, first run (`_first_run`: welcome for an empty library, else `setup_done` silently)
- `app/ui/settings_dialog.py` — preferences dialog in plain words: General (when I download = torrent program on this PC with its status / a program on a NAS or another computer with RemoteProgramForm / a folder with the magnet-only note, quality by plain name, week start, Movies key + key guide link, updates) and Advanced (sites, word filters, Prowlarr); both tabs scroll when the screen is short (height capped by `dialog_height`); pure helpers quality_name / quality_from_name, download_rows, download_dir_to_save (APP mode keeps the stored folder); validation errors open their tab
- `app/ui/welcome_dialog.py` — WelcomeDialog (first run, 4 steps: welcome → already on airdates.tv? (optional import via AirdatesImportPanel) → how to download (torrent program found / install qBittorrent, a program on a NAS or another computer with RemoteProgramForm (the cards scroll when it is open), or a folder) → TMDB key; fixed size, saves as it goes, Finish checks an unchecked key first, X = done) and its pure helpers (first_run_action, download_changes, changes_error, finish_changes, elide_path)
- `app/ui/torrent_app_status.py` — TorrentAppStatus: the torrent-program status line + "Install qBittorrent" (find / install through `services.torrent_app`), shared by the welcome and Settings; pure torrent_look
- `app/ui/remote_program_form.py` — RemoteProgramForm (program menu, address with each program's port as hint, user name, password, destination, "Verify the certificate (https)", Test connection + result line; the host's `run_test` saves first), shared by Settings → General and the welcome; pure helpers (program names, `remote_changes`, `folder_note`, `describe_error`, `result_look`)
- `app/ui/tmdb_key_guide.py` — TmdbKeyGuide (numbered steps to get a TMDB key, entry + Check through DiscoveryService) and TmdbKeyDialog (the guide on its own for Settings; Save checks an unchecked key first, stores it, `on_saved`); `key_action` = what Finish / Save does with the entry
- `app/ui/dialog_kit.py` — the roomy setup dialogs' sizes, primary/secondary buttons, heading row, links, placing + activating a modal dialog
- `app/ui/tray.py` — TrayIcon (pystray on its own daemon thread; menu Open / Check for new episodes now / Quit, `notify`; callbacks only via `call_soon_threadsafe`), TrayHost (close to tray, show again, quit, a second start's show request, fallback to close = quit), TrayNotice (first close: "AirGrabber keeps running"), pure `close_action`
- `app/ui/tasks.py` — spawn / async_command / cancel_all
- `app/ui/theme.py` — colours and fonts
- `app/ui/branding.py` — bundled logo (`load_logo`) and window icon (`set_window_icon`, call in every window's __init__)
- `app/assets/` — logo.png and multi-size airgrabber.ico (shipped with the app, so updates bring new artwork)
- `app/ui/widgets.py` — reusable widgets: MessagePanel, FlexGrid (responsive grid), PosterImage (async poster, `set_on_click`), LoadingBar, show_info()
- `app/ui/cards.py` — ShowCard (Tracked grid / search results; Tracked: info line + "Download new episodes" switch), pure `card_info_line`
- `app/ui/calendar_cards.py` — calendar cards: EpisodeCard (poster), CompactEpisodeCard, SuggestionCard
- `app/ui/download_control.py` — the cards' one-click Download row (⬇ Download + ⋯ = search window; working / ✓ outcome / nothing-found states) and DownloadStates (run state per title, owned by MainWindow, survives page rebuilds)
- `app/ui/search.py` — SearchSuggestions (header dropdown) and SearchResultsWindow
- `app/ui/show_details.py` — ShowDetailsWindow (a show's poster, meta line, summary with More, Next line, + Track / ✓ Following + switch, IMDb; season chips; episode rows with ✓ Downloaded / the Download row / when it airs) and ShowWindows (one window per show, owned by MainWindow; opened from show cards' covers on Search / Discover (via `resolve`) and My shows' poster/title; reloads on library and download changes); pure helpers meta_line, next_line, default_season, season_episodes, episode_row_state, upcoming_text
- `app/ui/indexer_dialog.py` — IndexerDialog ("Advanced Indexer Interrogation"): torrent search for an episode / season pack / film, ttk results table, grabs; TvTarget / MovieTarget
- `app/ui/media_cards.py` — MovieCard, DiscoverShowCard (lazy TMDB details), shared ⓘ IMDb icon
- `app/ui/tooltip.py` — hover tips: `add_tooltip(widget, text)` (500 ms delay, one shared borderless window, hides on leave / click / destroy), pure `tip_position` (below, flipped above, clamped to the widget's monitor)
- `app/ui/text_fit.py` — width-aware text fitting: elide_to_width, fit_to_lines, title_lines
- `app/ui/import_dialog.py` — ImportShowsDialog, tabs "Show names" (paste names / TVMaze ids) and "From airdates.tv"
- `app/ui/airdates_import.py` — AirdatesImportPanel (paste airdates.tv's "Export your color selection" text → review the TVMaze matches → import), used by the welcome setup and the import dialog; pure text/tick helpers
- `app/ui/views/` — one module per page: base (BaseView, StatusReporter), calendar (grid + layout helpers), tracked (grid, import, cleanup), shelves (ShelvesView base for TMDB pages), discover (TV shelves), movie (movie shelves)
- `tools/import_legacy.py` — one-shot import of 1.x JSON files
- `tools/sync_repo.py` — copy the publishable files into the git clone before a release
- `tests/` — unittest suites; `tests/fixtures/` holds recorded API payloads (`prowlarr_setup/`: Prowlarr config.xml files and the indexer/app-profile API answers used by test_prowlarr_setup; `qbittorrent/` and `transmission/`: answers built from their API docs, see each README.md); `tests/multipart.py` reads multipart bodies for the fake servers
- `airgrabber.py`, `*.json` at root — legacy 1.x app and its data (read-only reference)
