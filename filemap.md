# File map

- `main.py` — entry point: `--tray` (start hidden, `parse_options`), logging, single-instance lock (a second start shows the running window and exits 0), package check, Services, MainWindow, async Tk loop, shutdown, applying a background-downloaded update (`apply_staged`), tray icon stop, restart after an update (lock released first)
- `install.ps1` — one-command Windows installer (winget set up when missing: registered, else downloaded from winget's pinned GitHub release; Python via winget/python.org; app into %LOCALAPPDATA%\Programs\AirGrabber; shortcuts; the Prowlarr question and the failure report in small dark Windows Forms windows)
- `README.md` — GitHub front page: install / update / uninstall
- `app/bootstrap.py` — launch-time requirements check: pip-installs missing/outdated packages with a plain-tkinter progress window (stdlib only)
- `app/__init__.py` — APP_NAME, __version__
- `app/identity.py` — `APP_USER_MODEL_ID` (`drunkgummyboy.AirGrabber`, also install.ps1's `$AppId`) and `set_process_app_id` (main.py, before the first window or tray icon: AirGrabber's own taskbar group and notification name instead of Python's); ctypes, stdlib only, no-op off Windows
- `app/shortcut_app_id.cs` — C# helper compiled by Windows PowerShell 5.1's Add-Type: `[AirGrabber.ShortcutAppId]::Get` / `Set` a shortcut's (.lnk) AppUserModelID, keeping the rest of the shortcut; used by install.ps1 and app/services/powershell.py
- `app/single_instance.py` — InstanceLock: named mutex `Local\AirGrabber` + auto-reset event `Local\AirGrabber-show` (a second start sets it, the running copy polls it); ctypes, stdlib only, no-op off Windows
- `app/config.py` — AppPaths (data dir, db, posters, logs, torrents = APP-mode .torrent cache), logging setup
- `app/database.py` — schema + migrations (append-only; v2 = `tracked_shows.auto_since` + `auto_attempts`, every switch reset to off; v3 = `watchlist`; v4 = `have_episodes`, the "I already have this" marks), Database (locked shared connection), LibraryRepository (incl. the auto-download switch and due / give-up queries, `missing_counts` (one query for every tracked show, the SQL twin of app/services/missing.py's rule) and the have marks), HistoryRepository (recording a film's grab also deletes its watchlist row), WatchlistRepository (films as Movie JSON + release dates, switch, tries / give-up), SettingsRepository; all SQL; v6 = `subtitle_files` (per video file and language: tries, given up, saved) and `subtitle_grabs` (the languages a grab is complete for), `SUBTITLES_MIGRATION`; SubtitleRepository (`grabs_since`, `files`, `record_try` / `record_saved`, `mark_grab_done`, `show_languages`)
- `app/models/domain.py` — Show, Episode, LibraryEntry, ShowDetails (incl. `latest_season`, `missing`, `have`), LibraryStats, CalendarEntry, Movie, SearchKind, SearchRequest, TorrentRelease, DownloadRecord, GrabOutcome (SAVED/SENT/OPENED), QuickDownloadResult, MissingProgress / MissingRunReport ("Download missing"), auto-download events (AutoDownloaded / AutoGaveUp / AutoError, and for watchlist films AutoMovieDownloaded / AutoMovieGaveUp) and AutoDownloadReport, WatchlistEntry, TorrentApp, ProwlarrSetupResult, ImportMatch / AirdatesPreview (airdates.tv import preview); subtitles: SubtitleFile, SubtitleGrab, SubtitleQuota, SubtitleAccount, events SubtitlesSaved / SubtitleProblem (SubtitleEvent), SubtitleRunReport
- `app/models/settings.py` — Settings model (incl. the hidden `prowlarr_seeded_url` run-once marker, `setup_done` first-run flag and `last_run_version`; `auto_update`; `auto_download_new_shows`; tray: `keep_in_tray`, the `tray_notice_shown` marker, `start_with_windows`), DownloadMode (APP = open in the torrent program / REMOTE = send to the torrent program on a NAS or another computer / FOLDER = save to a folder, default; field `download_mode`), RemoteKind (SYNOLOGY / QBITTORRENT / TRANSMISSION, `.program` = short name) and the `remote_*` fields (`remote_configured`, pure `remote_ready`; a before-validator moves 2.0's `ds_*` keys into them, the next save prunes those), QualityProfile, Weekday; subtitles: `subtitles_enabled`, `subtitle_languages` (SUBTITLE_LANGUAGES = the offered OpenSubtitles codes and names), `subtitles_folder`, the user's optional OpenSubtitles account `opensubtitles_username` / `opensubtitles_password`, the user's optional own API key `opensubtitles_own_key` (replaces the shipped key when filled in; an older build's `opensubtitles_api_key` is still ignored on load and dropped by the next save); `card_size` (CardSize XS / S / M / L / XL, default XL = the original cards)
- `app/models/tvmaze.py` — TVMaze wire schemas → domain models
- `app/models/tmdb.py` — TMDB wire schemas → domain models (release-date/certification extraction)
- `app/models/opensubtitles.py` — OpenSubtitles wire schemas (login, /infos/user, /subtitles, /download, the 406 quota answer) → SubtitleCandidate (one file, not machine- or AI-translated) and SubtitleLink
- `app/models/types.py` — shared annotated field types, strip_html
- `app/services/__init__.py` — Services composition root (create/aclose)
- `app/services/library.py` — LibraryService: `show_details` (ShowDetails for the details window: tracked shows from the library, others from TVMaze kept 15 min in memory, never stored; pure `next_episode`, `downloaded_ids`), track/search/import (new shows get the auto-download switch per `auto_download_new_shows`), `set_auto_download`, `activity` (Tracked cards: latest grab of the past week + next episode, ShowActivity), incremental + periodic sync, calendar suggestions (cached TVMaze schedule), missing episodes (`missing_episodes`, `missing_counts`, `mark_have` / `unmark_have` + notify), change listeners; calendar_range(); `find_matches` (names → TVMaze matches without tracking; shared best-hit rule with `import_shows`, a "(YYYY)" / "(US)" suffix prefers that year / country)
- `app/services/airdates.py` — airdates.tv import: `parse_export` ("Export your color selection" text → series ids), AirdatesClient (`show_name` via `/s?q=info:<id>`, one request at a time 0.3 s apart, one retry; an unknown id answers 500), AirdatesImportService (`services.airdates`: `find` → AirdatesPreview; import the ticked ids with `library.import_shows`), AirdatesError
- `app/services/tvmaze.py` — TVMazeClient (async, rate-limit aware retries), TVMazeError/TVMazeNotFound
- `app/services/images.py` — ImageCache: memory LRU of resized posters over a disk cache; deduped downloads
- `app/services/tmdb.py` — TMDBClient (v3 key or v4 token, retries, key never in logs/errors; `check_key` = one /authentication call for an unsaved key), TMDB* errors
- `app/services/discovery.py` — DiscoveryService: TV/movie dashboards (30 min cache), details (24 h), TMDB→TVMaze `resolve` (show details) and tracking, `check_tmdb_key`
- `app/services/settings.py` — SettingsService (in-memory current settings, validated updates serialized by a lock, listeners)
- `app/services/updates.py` — UpdateService: version check against GitHub, `install` (download + swap APP_ENTRIES with rollback), `stage` (download + unpack into `.update/new` with a ready marker) and `register_install`; `apply_staged` (main.py at exit: swap in a staged update newer than the files on disk, else delete it); never in a dev copy
- `app/services/startup.py` — start with Windows: the Startup-folder `AirGrabber.lnk` (pythonw, `main.py --tray`), pure `shortcut_spec`, `is_enabled` / `set_enabled` (written by PowerShell's WScript.Shell, removed by deleting it); injectable Startup folder; stdlib only
- `app/services/powershell.py` — `run_powershell` (Windows PowerShell 5.1 without a console window, extra environment variables, timeout; cancelling waits so a shortcut is never half-written), `powershell_exe`, `LOAD_HELPER` / `helper_env` (compile app/shortcut_app_id.cs once per run); injectable `PowerShellRunner`; stdlib only
- `app/services/app_identity.py` — `ensure_start_menu_app_id` (main.py, once per launch in the background): gives an older install's Start-menu AirGrabber.lnk the AppUserModelID when its Arguments start this install's main.py and it has none; never in a development copy or to other shortcuts; pure `first_argument` / `skip_reason` / `parse_read_output`; injectable runner and Start-menu folder
- `app/services/install_info.py` — `ensure_uninstall_entry`: the HKCU "Installed apps" entry, mirroring install.ps1's Register-Uninstaller (create when missing, else refresh DisplayVersion of this folder's entry only); injectable registry; stdlib only
- `app/services/downloads.py` — DownloadService.grab() by `download_mode`: FOLDER = .torrent → watch folder (direct link, then itorrents), else magnet → the remote program (RemoteDownloads, when configured); REMOTE = .torrent (direct link, then itorrents) or else a magnet (own / Prowlarr redirect / built from the hash) → the remote program (`add_torrent` / `add_magnet`, "Sent to <program>"); APP = .torrent → `AppPaths.torrents` cache (pruned to 50) or else a magnet (own / Prowlarr redirect / built from the hash), opened with os.startfile; history + listeners (`subscribe`: after every grab; `subscribe_grabs`: the grab's target, first)
- `app/services/torrent_app.py` — find_torrent_app() (read-only registry lookup of the magnet / .torrent handler, injectable reader, friendly names), install_qbittorrent() via winget, TorrentAppService (`services.torrent_app`)
- `app/services/search.py` — TorrentSearchService: request builders (`episode_request` and `movie_request` also module-level), concurrent indexer search streaming SearchUpdates (per-indexer status, timeout (an indexer's own `search_timeout` wins), cancellation); pure build_queries / is_relevant / passes_settings / is_preferred / merge / quality helpers
- `app/services/picking.py` — pure pick_best / rank_releases for the one-click Download: likely-fake filter (exe/zip/rar/password/codec words, too-small sizes), dead torrents, single episode before a pack, ranking by quality profile, preferred group, seeders, known size
- `app/services/missing.py` — missing episodes: pure `latest_season` (highest season with an aired regular numbered episode) and `missing_episodes` (its aired regular numbered episodes neither downloaded nor marked "I already have this", oldest first); MissingDownloadService (`services.missing`): `download_missing` (one run per show, MissingRunBusy; max 25, oldest first, through QuickDownloadService; nothing found = next; a failed grab stops the run; progress per episode)
- `app/services/quick_download.py` — QuickDownloadService (`services.quick_download`): one download per target at a time (per-target lock; a target already in the history returns `already_downloaded` without searching) → search (30 s cap) → pick_best → DownloadService.grab; UI-independent
- `app/services/auto_download.py` — AutoDownloadService (`services.auto_download`): download new episodes of shows whose switch is on — `run_once` (lock; give up 3 days after airing, then due episodes 2 h after airing, least-tried then oldest first, max 5, through QuickDownloadService; a failed grab = one AutoError and the run stops; then, unless a grab failed, the due watchlist films (release dates refreshed first, max 5, AutoMovieDownloaded / AutoMovieGaveUp; a film downloaded before it was listed gets its switch turned off)), `run_periodic` (startup + every 30 min, from MainWindow._start), event `subscribe`
- `app/services/watchlist.py` — WatchlistService (`services.watchlist`): the movie watchlist in memory (`load` in Services.create; `contains` / `entries` newest first / `entry`), `add` (switch on by default, then TMDB release dates) / `remove` / `set_auto_download` / `record_try` / `refresh_release_dates` (stale after 24 h; skipped without a TMDB key), `due`, listeners; a grabbed film leaves the list (`DownloadService.subscribe_grabs`); pure rules `available_on` (digital release, else theatrical + 60 days), `is_out`, `is_due` (switch on, out, searched at most every 4 h), `should_give_up` (30 days after the first search), `needs_refresh`, `due_order`
- `app/services/opensubtitles.py` — `APP_API_KEY` (AirGrabber's one shipped API key; empty = subtitles not offered in this version), `effective_api_key` (the user's own key when filled in, else the shipped one; wired in app/services/__init__.py), OpenSubtitlesClient (`own_key` says whose key is in use, so a refusal names it: KEY_REJECTED_TEXT / OWN_KEY_REJECTED_TEXT; `check_key` = one GET /infos/formats with an unsaved key, no session) (api.opensubtitles.com/api/v1: Api-Key + "AirGrabber v…" User-Agent headers, `configured`, sorted lowercase GET parameters, 4 requests a second, `sign_in` / `ensure_session` (POST /login, password in the body only, token in memory 23 h, the `base_url` host (api. / vip-api.) only, refused credentials not sent again), `search`, `download_link` (remaining + reset), `fetch` (the temporary link, without key or token); KeyRejected / LoginRejected / QuotaExceeded (406) / Unreachable in plain words, no URLs or secrets), `movie_hash` (OpenSubtitles hash), `imdb_number`
- `app/services/subtitle_files.py` — finding a grab's videos in the finished-downloads folder: `scan_folder` (bounded depth/entries; hidden, @eaDir, #recycle skipped; videos, partial downloads, subtitle files; growing = changed in the last 5 min), `grab_files` (a folder/file named like the release, or "Show Name S02E04" / a film's "Title Year"; season packs per episode; samples never), names (`normalize`, `parse_episode`, `movie_identity`), `subtitle_path` (<stem>.<lang>.srt), `has_subtitle`, `write_new_file` (atomic, never over an existing file); pure + blocking I/O
- `app/services/subtitles.py` — SubtitleService (`services.subtitles`; nothing without `APP_API_KEY`; the user's free account is optional (every run signs in with it when saved: 20 downloads a day, else 5 per IP)): `run_periodic` (a minute after start, every 30 min, soon after a subtitle setting changes), `run_once` (grabs of the last 30 days not complete for the languages → scan in a thread → per video and language: existing file counts, else moviehash search, then IMDb id / name; `pick` = hash match, not hearing-impaired, most downloads; retry after 4 h, give up 5 days after the first try; stop at the day's quota until it resets; problems as SubtitleProblem at most every 3 h), `available`, `sign_in`, `check_key` (Settings' own key), `quota`, `show_languages`, event `subscribe`
- `app/services/prowlarr_setup.py` — ProwlarrSetupService: finds a Prowlarr on this PC (%ProgramData%\Prowlarr\config.xml, `parse_config`), waits for /ping, verifies and saves URL + key when none is configured; then once per local Prowlarr adds the CURATED public sites (Prowlarr tests each), marker `prowlarr_seeded_url`
- `app/services/synology.py` — DownloadStationClient (DSM Web API discovery, POST login, DS2/DS task create from a magnet or an uploaded .torrent (multipart), logout); `DownloadStationError` = older name of RemoteError
- `app/services/remote.py` — what the remote torrent programs share: RemoteClient protocol (`kind`, `test`, `add_magnet`, `add_torrent`), RemoteError, HttpClients (short-lived clients honouring `remote_verify_tls`, cached SSL contexts), host / TLS / redirect failure texts without URLs or secrets
- `app/services/qbittorrent.py` — QBittorrentClient (Web API v2: form login "Ok."/"Fails.", Referer + Origin for its CSRF check, app/version, multipart torrents/add with `urls` / `torrents` + `savepath`, logout; no sign-in without a user name)
- `app/services/transmission.py` — TransmissionClient (RPC at `<url>/transmission/rpc`: 409 session-id handshake, Basic auth, `session-get` version, `torrent-add` with `filename` / `metainfo` + `download-dir`), `rpc_url`
- `app/services/remote_downloads.py` — RemoteDownloads (`services.remote`, also `services.station`): the client for `Settings.remote_kind` on every call (`client()`), `configured`, `kind`, `test()`; `make_clients`
- `app/indexers/` — torrent indexers (Strategy pattern): base (BaseIndexer contract incl. optional `search_timeout`, IndexerError, shared GET-JSON/retry helper with per-request timeout, USER_AGENT), apibay, eztv (by IMDb id, paged), bitsearch, yts (MOVIE only, base-URL fallback), prowlarr (X-Api-Key, 30 s search read timeout, 40 s cap, `test()`); `default_indexers()` builds all five
- `app/ui/main_window.py` — root window (`_card_scale`: the cards' size from Settings, handed to the pages, read at every load; a search-results window keeps the size it opened with) (also runs "Download missing" and the have marks, MissingActions): header (mode switch, logo, search, settings), pages (reloaded on settings changes except off-page ones — connections, `download_mode`, `setup_done`, `auto_update`, `last_run_version`, `auto_download_new_shows`, the tray ones: `settings_affect_pages`), `tray` (TrayHost: WM_DELETE_WINDOW, `--tray` start hidden), status bar (update badge / "Restart to update", "Updated to v…" notice `update_notice`, Prowlarr setup message, the automatic downloads' notices `auto_notice` for episodes and watchlist films, errors held back by `AutoNoticeThrottle`), background update staging, update + restart, first run (`_first_run`: welcome for an empty library, else `setup_done` silently); starts the subtitle runs, shows their problems in the status bar (`subtitle_status_text`) and hands the show windows their CC marks
- `app/ui/settings_dialog.py` — preferences dialog in plain words: General (when I download = torrent program on this PC with its status / a program on a NAS or another computer with RemoteProgramForm / a folder with the magnet-only note, quality by plain name, week start, Card size (segmented XS–XL + hover tip), Movies key + key guide link, updates) and Advanced (sites, word filters, Prowlarr); both tabs scroll when the screen is short (height capped by `dialog_height`); pure helpers quality_name / quality_from_name, download_rows, download_dir_to_save (APP mode keeps the stored folder); validation errors open their tab; General's Subtitles section (with `subtitles`: without a shipped key one line "Subtitles aren't available in this version yet"; else the credit "Subtitles provided by OpenSubtitles.com", the switch + downloads left today, and while on: language tags, "Where finished downloads end up" + Choose…, the optional free account (20 a day instead of 5, "Create a free account" link) with Sign in, the optional own OpenSubtitles key (OwnKeyRow) with Check; Save checks `subtitle_problem` first, then a new own key (refused = not saved, unreachable = saved))
